# AI Financial Analyst

A web-based financial analytics dashboard built using Python, Pandas, Flask, and Chart.js.

## Project Overview

The AI Financial Analyst allows users to upload financial data in Excel or CSV format and analyze company-level financial performance through an interactive dashboard.

## Features

- Upload financial data using Excel or CSV files
- Select and analyze different companies
- View key financial KPIs
- Calculate average revenue growth
- Analyze revenue and net income trends
- View total assets and liabilities
- Analyze operating cash flow
- Interactive charts using Chart.js
- Rule-based natural-language financial Q&A

## Technologies Used

- Python
- Pandas
- Flask
- OpenPyXL
- HTML
- CSS
- JavaScript
- Chart.js
- Excel / CSV

## Key KPIs

The dashboard displays:

- Revenue
- Net Income
- Average Revenue Growth
- Total Assets
- Total Liabilities
- Operating Cash Flow

## How to Run

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the application

```bash
python app.py
```

### 3. Open the dashboard

Open your browser and go to:

```text
http://127.0.0.1:5000
```
